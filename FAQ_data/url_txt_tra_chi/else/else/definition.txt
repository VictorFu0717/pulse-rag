Subdomain（子域名）：子域名是主域名下的下一級域名，位於主域名之前並用句號分隔。例如，mail.example.com中的mail就是子域名。子域名常用於組織不同的網站區域或服務，例如api.example.com、blog.example.com等。若要新增子域名必須在DNS中新增紀錄設定，無需另外購買。

Renew SSL（續用 SSL 憑證）：續用 SSL 憑證是在現有 SSL 憑證即將過期前，向憑證商（CA）申請新的憑證以確保網站憑證可正常使用。續用過程中會保持相同的FQDN，但會獲得一個新的憑證檔案和新的有效期限。

Reissue SSL（更新SSL 憑證）：更新SSL 憑證是向憑證商申請重新核發已購買的 SSL 憑證，通常在以下情況發生：變更FQDN、私鑰遺失、延長到期日。與續用不同的是，更新適用於同一張訂單的憑證，而非購買新的憑證。

SSL Private Key（SSL 私鑰）	：SSL 私鑰是用於解密通過 SSL/TLS 協議傳輸的加密資料的密鑰。它必須與公鑰（包含在 SSL 憑證中）配對使用。私鑰應該嚴格保護，絕不應洩露或與他人共享，因為任何人只要擁有私鑰，就可以冒充擁有該憑證的伺服器。

SSL PFX File（PFX 檔案）：PFX 檔案（Personal Information Exchange）是一種包含 SSL 憑證和其對應私鑰的格式，通常使用.pfx做為副檔名，特別常用於 Windows 伺服器。

CSR（CSR文件）：CSR（Certificate Signing Request）是向憑證商申請 SSL 憑證時所需的請求檔案。CSR 包含申請者的公鑰和組織資訊（如公司名稱、部門、位置、域名等），但不包含私鑰。申請者在申請 SSL 憑證時需要提交 CSR，憑證商會驗證資訊後簽署並頒發 SSL 憑證。

A Record（A 記錄）：A 記錄是 DNS的一種記錄類型，用於將域名對應到 IPv4 位址。當使用者在瀏覽器中輸入域名時，DNS 伺服器會查詢 A 記錄，找到對應的 IP 位址，然後導向該伺服器。例如，A 記錄可能將example.com對應到192.168.1.1這樣的 IPv4 位址。重要規則：A 記錄無法設定萬用字元（*），每個域名或子域名需要單獨設定 A 記錄；A 記錄只能對應 IPv4 位址，不能對應 IPv6 位址（IPv6 應使用 AAAA 記錄）；一個域名可以設定多個 A 記錄。

Wildcard（萬用符號）：萬用字元域名是一種特殊的 SSL 憑證或 DNS 設定，使用星號（*）代表子域名。例如，*.example.com的萬用字元憑證可以保護api.example.com、mail.example.com、blog.example.com等所有第一級子域名。

DNS：DNS 是一個全球分散式的網路系統，將人類可讀的域名（例如example.com）轉換為電腦可識別的 IP 位址（例如192.168.1.1）。DNS 伺服器像一個電話簿，當使用者存取網域時，DNS 會查詢並返回對應的 IP 位址，讓使用者的設備能連接到正確的伺服器。DNS 還管理其他類型的記錄，如 MX 記錄（郵件）、CNAME 記錄（別名）等。

Domain Restore（域名贖回）：域名逾期並進入贖回期後必須支付贖回費用才可以延長域名年限並恢復解析，若進入贖回期後的一定時間內未完成贖回作業，域名將會被管理局刪除並釋出。

Expired（過期）：過期通常指 SSL 憑證或域名的有效期限已終止。過期的 SSL 憑證將導致瀏覽器顯示安全警告，使用者可能無法安全地存取網站。過期的域名則會失效，網域可能被他人購買或進入特殊的恢復期。定期檢查和更新憑證及域名的有效期是維持網站正常運作的重要工作。
